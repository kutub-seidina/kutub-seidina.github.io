# مكتبة سَيْدِنا — صفحة إعادة الكتب

صفحة ويب عربية وإنجليزية مخصصة لمساعدة من يعثر على كتاب تابع لمكتبة **سَيْدِنا** على إرسال بلاغ سريع والتنسيق لإعادته إلى صاحبه.

المشروع ثابت وخفيف، ويعمل مباشرة عبر **GitHub Pages** دون خادم خلفي أو قاعدة بيانات، ويستخدم خدمة **FormSubmit** لإرسال البلاغات إلى بريد المكتبة.

---

## فكرة الصفحة

عند العثور على كتاب يحمل اسم أو ختم المكتبة، يستطيع المستخدم:

1. إدخال اسم الكتاب أو إرفاق صورة واضحة لغلافه.
2. إضافة مكان العثور على الكتاب إن كان معروفًا.
3. كتابة تفاصيل إضافية اختيارية.
4. اختيار وسيلة الرد المناسبة.
5. إرسال البلاغ إلى بريد المكتبة لترتيب إعادة الكتاب.

---

## المزايا الرئيسية

### دعم العربية والإنجليزية

- دعم كامل للغتين العربية والإنجليزية.
- تحديد اللغة تلقائيًا من لغة المتصفح عند الزيارة الأولى.
- حفظ تفضيل اللغة في `localStorage`.
- التبديل الفوري بين اتجاهي `RTL` و`LTR`.
- ترجمة العناوين والحقول والأزرار ورسائل التحقق وصفحة النجاح.
- المحافظة على البيانات المدخلة والصورة المختارة عند تبديل اللغة.
- منع وميض اللغة أثناء تحميل الصفحة.

### تنظيم رسائل البريد

- استخدام موضوع عربي ثابت لرسائل البلاغ.
- إرسال أسماء الحقول باللغة العربية.
- تحويل قيم وسيلة التواصل البرمجية إلى مسميات عربية واضحة.
- إرسال لغة الواجهة باسم «العربية» أو «الإنجليزية».
- استخدام قالب `basic` في `FormSubmit` لتجنب جدول `Name / Value`.
- قد تبقى بعض النصوص الثابتة التي تنشئها خدمة `FormSubmit` باللغة الإنجليزية.

### حفظ مسودة البلاغ مؤقتًا

- حفظ الحقول النصية داخل `sessionStorage`.
- استعادة المسودة بعد إعادة تحميل الصفحة في الجلسة نفسها.
- الحفظ المؤجل بعد توقف المستخدم عن الكتابة.
- الحفظ الفوري قبل الإرسال وعند مغادرة الصفحة.
- عدم حفظ صورة الغلاف أو محتواها في التخزين.
- إظهار تنبيه عند الحاجة إلى إعادة إرفاق الصورة.
- إمكانية حذف المسودة يدويًا وتصفير النموذج بالكامل.
- حذف المسودة بعد نجاح الإرسال.

> بيانات المسودة مرتبطة بجلسة علامة التبويب الحالية، وتنتهي عادةً عند إغلاقها.

### التحقق وتجربة الاستخدام

- يكفي إدخال اسم الكتاب أو إرفاق صورة الغلاف.
- التحقق من حجم الصورة ونوعها وسلامة محتواها.
- التحقق من البريد الإلكتروني ورقم الهاتف واسم مستخدم تيليغرام.
- عرض ملخص واضح للأخطاء مع نقل التركيز إلى أول حقل غير صحيح.
- ترجمة الأخطاء الظاهرة فور تبديل اللغة.
- منع الإرسال المتكرر أثناء معالجة الطلب.
- احترام إعداد `prefers-reduced-motion`.
- دعم الاستخدام بلوحة المفاتيح والتركيز المرئي.
- عرض وسيلة التواصل وبيانات التواصل في عمودين على الشاشات الواسعة، وتحويلهما إلى صفين كاملَي العرض عند `600px` أو أقل.

### الخصوصية

- لا تُرسل البيانات إلا بعد ضغط زر الإرسال.
- تُرسل البلاغات عبر خدمة `FormSubmit` إلى بريد المكتبة.
- لا تُستخدم بيانات التواصل إلا لترتيب إعادة الكتاب.
- لا تُحفظ صورة الغلاف داخل `sessionStorage`.
- لا تُحفظ بيانات النموذج في `localStorage`.
- تُحذف المسودة بعد الوصول الناجح إلى صفحة التأكيد.

### مسؤولية الملفات

| الملف | المسؤولية |
|---|---|
| `index.html` | الصفحة الرئيسية ونموذج البلاغ |
| `thanks.html` | صفحة تأكيد نجاح الإرسال |
| `README.md` | توثيق فكرة المشروع ومزاياه وإعداده ونشره واختباره |
| `assets/css/styles.css` | تصميم الصفحتين ودعم RTL وLTR والاستجابة للشاشات |
| `assets/js/i18n.js` | قاموس الترجمة وتحديد اللغة وتبديلها |
| `assets/js/main.js` | التحقق، الصور، المسودة، الإرسال، ورسائل الواجهة |
| `assets/js/thanks.js` | التحقق من نجاح الإرسال وحذف المسودة ومعالجة الرجوع |

## طريقة عمل الإرسال

1. يتحقق JavaScript من صحة الحقول والصورة.
2. تُحفظ آخر نسخة من المسودة داخل الجلسة.
3. تُجهّز بيانات الإرسال، بما يشمل لغة الواجهة وموضوع البريد ووسيلة التواصل بصياغة عربية.
4. يُنشأ رمز إرسال فريد.
5. يُرسل النموذج إلى خدمة `FormSubmit` باستخدام القالب `basic`.
6. بعد نجاح الطلب، ينتقل المستخدم إلى `thanks.html`.
7. تتحقق صفحة النجاح من رمز الإرسال.
8. تُحذف المسودة وعلامة الإرسال المؤقتة.
9. عند الرجوع إلى الصفحة الرئيسية، يُصفّر النموذج لمنع ظهور بيانات البلاغ السابق.

## إعداد المشروع

يمكن تعديل الإعدادات الأساسية من كائن `CONFIG` داخل:

```text
assets/js/main.js
```

الإعدادات المتاحة:

```javascript
const CONFIG = {
  libraryName: "اسم المكتبة",
  email: "البريد الإلكتروني",
  siteUrl: "رابط الموقع المنشور"
};
```

يجب أن يكون `siteUrl` هو الرابط النهائي للموقع دون شرطة مائلة في النهاية.

## التشغيل محليًا

يمكن فتح `index.html` مباشرة في المتصفح، لكن يفضّل تشغيل خادم محلي لتجربة السلوك بصورة أقرب إلى GitHub Pages.

مثال باستخدام Python:

```bash
python -m http.server 8000
```

ثم افتح:

```text
http://localhost:8000
```

## ملاحظات مهمة

- لا تُحفظ صورة الغلاف بعد إعادة تحميل الصفحة.
- `sessionStorage` لا يضمن بقاء المسودة بعد إغلاق علامة التبويب.
- يجب تفعيل عنوان البريد في خدمة `FormSubmit` قبل استقبال أول بلاغ فعلي.
- صفحة النجاح تحمل توجيه `noindex` حتى لا تظهر في نتائج البحث.
- تُرسل أسماء حقول البلاغ وموضوع الرسالة ووسيلة التواصل باللغة العربية لتسهيل قراءة الرسائل المستلمة.
- قد تبقى بعض العبارات الثابتة التي تضيفها خدمة `FormSubmit` باللغة الإنجليزية، لأنها ليست جزءًا من ملفات المشروع.
